# Podcast Bumpers

Bumpers for podcast/interview content (video podcast format).

## Style Guidelines

- **Tone:** Professional, conversational, branded
- **Duration:** Intro 5-8 sec, Outro 10-15 sec
- **Colors:** Consistent brand colors, good contrast
- **Typography:** Bold, readable, podcast branding
- **Animation:** Smooth, audio-reactive elements optional

## Suggested Templates

| Template | Duration | Description |
|----------|----------|-------------|
| Intro_Podcast_Full.setting | 8 sec | Full branded intro with music |
| Intro_Podcast_Episode.setting | 5 sec | Episode number + guest name |
| Outro_Podcast_Subscribe.setting | 12 sec | Platform links (Spotify, Apple, etc.) |
| Outro_Podcast_Next.setting | 10 sec | Next episode teaser space |

## Typical Structure

**Intro:**
```
[Podcast Logo]
[Show Name]
[Episode # / Guest Name]
[Tagline]
```

**Outro:**
```
[Thanks for listening]
[Platform icons: Spotify, Apple Podcasts, YouTube]
[Website/RSS]
[Next episode date (optional)]
```

## Color Palette (Professional)

```
Background:         #0d1117 / RGB(0.05, 0.07, 0.09)
Primary:            #58a6ff / RGB(0.35, 0.65, 1.0)
Secondary:          #f78166 / RGB(0.97, 0.51, 0.40)
Text:               #c9d1d9 / RGB(0.79, 0.82, 0.85)
```

## Audio Considerations

- Podcast intros typically have music/jingle
- Leave audio space for voiceover ("Welcome to [Show]...")
- Outro should have fade-out friendly timing
- Consider audio waveform visualization element

## Platform Icons

Include platform icons for:
- Spotify
- Apple Podcasts
- Google Podcasts
- YouTube
- RSS
