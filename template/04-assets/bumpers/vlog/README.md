# Vlog Bumpers

Bumpers for personal vlog content.

## Style Guidelines

- **Tone:** Personal, casual, engaging
- **Duration:** Intro 2-3 sec (short), Outro 5-10 sec
- **Colors:** Warm, inviting, can be more colorful
- **Typography:** Friendly, modern sans-serif
- **Animation:** Dynamic, energetic but not overwhelming

## Suggested Templates

| Template | Duration | Description |
|----------|----------|-------------|
| Intro_Vlog_Casual.setting | 2 sec | Quick name/logo reveal |
| Intro_Vlog_Location.setting | 3 sec | With location text placeholder |
| Outro_Vlog_Social.setting | 8 sec | Social media links focus |

## Typical Structure

**Intro:**
```
[Quick logo animation]
[Episode/Topic text (optional)]
```

**Outro:**
```
[See you next time]
[Social handles]
[Subscribe reminder]
```

## Color Palette (Warm)

```
Background:         #faf3e0 / RGB(0.98, 0.95, 0.88)
Primary accent:     #f4a261 / RGB(0.96, 0.64, 0.38)
Secondary accent:   #2a9d8f / RGB(0.16, 0.62, 0.56)
Text (dark):        #264653 / RGB(0.15, 0.27, 0.33)
```

## Notes

- Keep intros very short - vlogs should feel immediate
- Consider adding location/date text overlay option
- Music cue more important than elaborate visuals
