# Coding Tutorial Bumpers

Bumpers for programming tutorial content.

## Style Guidelines

- **Tone:** Professional, educational, focused
- **Duration:** Intro 3-4 sec, Outro 5-20 sec
- **Colors:** Dark theme preferred (easier on eyes for code content)
- **Typography:** Clean, monospace accents for tech feel
- **Animation:** Subtle, not distracting

## Templates

| Template | Duration | Use Case |
|----------|----------|----------|
| IntroBumper_Modern.setting | 4 sec | Standard intro, dark theme |
| IntroBumper_Minimal.setting | 3 sec | Quick intro, light theme |
| OutroBumper_EndScreen.setting | 20 sec | YouTube end screen compatible |
| OutroBumper_Simple.setting | 5 sec | Quick outro with CTA |

## Typical Structure

**Intro:**
```
[Logo/Channel Name]
[Tagline: "Programming Tutorials"]
```

**Outro:**
```
[Thanks for watching]
[Channel Name]
[Subscribe CTA]
[End screen placeholders]
```

## Color Palette

```
Background (dark):  #1a1a2e / RGB(0.10, 0.10, 0.18)
Accent:             #4361ee / RGB(0.26, 0.38, 0.93)
Text (light):       #ffffff / RGB(1, 1, 1)
Text (secondary):   #a0a0a0 / RGB(0.63, 0.63, 0.63)
```
