# Shorts Lower Thirds

Lower thirds for vertical short-form content (YouTube Shorts, Instagram Reels, Facebook Reels).

## Critical: Safe Zones

```
┌────────────────────┐
│                    │
│   SAFE FOR TEXT    │  ← Upper 80%
│                    │
│                    │
│   Lower thirds     │  ← Position here (middle area)
│   go HERE          │
│                    │
├────────────────────┤
│  ⚠️ PLATFORM UI    │  ← Bottom 15-20% AVOID
│  (buttons, handle) │
└────────────────────┘
```

**Avoid bottom 20%** - Platform UI covers this area.

## Style Guidelines

- **Tone:** Bold, readable on mobile
- **Duration:** 2-3 seconds max
- **Position:** Middle-lower area (NOT bottom)
- **Animation:** Quick fade or pop, no elaborate animations

## Color Palette (High Contrast)

```
Primary (Blue):     #2e3192 / RGB(0.18, 0.19, 0.57)
Secondary (Green):  #58c034 / RGB(0.35, 0.75, 0.20)
Text (Light):       #ffffff / RGB(1, 1, 1)
Background:         #000000 @ 80% / Semi-transparent black
```

## Typography

```
Primary Font:    Inter (Bold)
Size (Name):     36-42px (larger for mobile)
Size (Role):     24-28px
```

**Position:** Y: 1200-1400px (safe from bottom UI)

## Lower Third Types

| Type | Content | Style |
|------|---------|-------|
| Name | Speaker name | Bold, centered |
| Handle | @username | With platform icon |
| Caption | Key point | Large text, high contrast |
| CTA | "Follow for more" | With animated arrow |

## Animation (Fast)

```
0.0s - 0.15s: Fade in
0.15s - 2.5s: Hold
2.5s - 2.7s: Fade out
```

## Platform-Specific Notes

### YouTube Shorts
- Username at bottom left
- Subscribe button bottom right
- Like/comment/share on right side

### Instagram Reels
- Username at bottom left with profile pic
- Audio info at bottom
- Like/comment/share on right

### Facebook Reels
- Similar to Instagram
- Share button prominent

## Design Tips

1. **Large text** - Must be readable on phone screens
2. **High contrast** - White on dark or vice versa
3. **Simple** - No elaborate designs, clean and bold
4. **Short duration** - 2-3 seconds max
5. **No bottom placement** - Platform UI will cover it
