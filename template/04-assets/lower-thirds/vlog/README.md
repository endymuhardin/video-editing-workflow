# Vlog Lower Thirds

Lower thirds for personal vlog content.

## Style Guidelines

- **Tone:** Personal, friendly, approachable
- **Duration:** 2-4 seconds
- **Position:** Bottom left or center
- **Animation:** Pop in with bounce, or typewriter effect

## Color Palette (Warm Variant)

Based on ArtiVisi palette with warmer adjustments:

```
Primary:            #2e3192 / RGB(0.18, 0.19, 0.57)
Accent (Warm):      #f4a261 / RGB(0.96, 0.64, 0.38)
Text (Dark):        #1a1a2e / RGB(0.10, 0.10, 0.18)
Background:         #ffffff / RGB(1, 1, 1)
```

## Typography

```
Primary Font:    Inter
Name Weight:     600 (Semibold)
Location Weight: 400 (Regular)
```

## Suggested Templates

| Template | Style | Use Case |
|----------|-------|----------|
| LowerThird_Location.setting | With map pin icon | Travel/location |
| LowerThird_Date.setting | Calendar style | Timestamping |
| LowerThird_Casual.setting | Handwritten accent | Personal moments |

## Lower Third Types

| Type | Primary | Secondary |
|------|---------|-----------|
| Location | City, Country | Context |
| Date | Date | Event name |
| Person | Name | Relationship |
| Time | Time of day | Activity |

## Animation Style

More playful than tutorial style:
- Bounce/elastic ease
- Icon animations (pin drop, etc.)
- Subtle scale on appear
