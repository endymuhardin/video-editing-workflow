# Shorts Thumbnails

Thumbnail guidelines for vertical short-form content.

## Platform Differences

| Platform | Thumbnail Use | Specs |
|----------|---------------|-------|
| YouTube Shorts | Shown in Shorts shelf | Auto-generated or custom |
| Instagram Reels | Cover image | 1080×1920 or frame select |
| Facebook Reels | Cover image | 1080×1920 or frame select |
| TikTok | Video cover | Frame select or upload |

## Specifications

### YouTube Shorts (Optional Custom)
```
Resolution:     1280 × 720 px (landscape, cropped to 9:16)
                or extract from video
```

### Instagram/Facebook Reels
```
Resolution:     1080 × 1920 px (vertical)
Aspect Ratio:   9:16
Format:         PNG or JPG
```

## Style Guidelines

- **Tone:** Eye-catching, bold, scroll-stopping
- **Colors:** High contrast, vibrant
- **Text:** Large, minimal (1-3 words)
- **Face:** Expressive (if showing face)

| Emoji | 96-128px | Native |
| CTA | 48-60px | Clear |

## Best Practices

### YouTube Shorts
- Often auto-selects frame
- Custom thumbnail less impactful (small display)
- Focus on strong first frame instead

### Instagram Reels
- Cover shows on profile grid
- Choose visually appealing frame
- Can upload custom cover

### TikTok
- First frame or custom
- Shows on profile grid
- Keep consistent style

## Frame Selection Tips

1. **High action moment** - mid-motion, peak emotion
2. **Clear face** - if showing face
3. **No motion blur** - sharp frame
4. **Good composition** - even as still image

## Must Have

1. **Scroll-stopping visual**
2. **Curiosity gap** (what happens next?)
3. **High contrast** (visible in small view)

## Avoid

- Blurry frames
- Dark/poorly lit moments
- Spoiling the payoff
- Text-heavy covers (platform UI covers bottom)
