# Coding Tutorial Thumbnails

Thumbnail guidelines for programming tutorial content.

## Specifications

```
Resolution:     1280 × 720 px (YouTube standard)
Aspect Ratio:   16:9
Format:         PNG or JPG
Max Size:       2 MB
```

## Style Guidelines

- **Tone:** Professional, educational, trustworthy
- **Colors:** ArtiVisi palette with high contrast
- **Text:** Large, readable at small sizes (mobile)
- **Face:** Include face for higher CTR (optional)

## ArtiVisi Palette

```
Primary:        #2e3192 (Deep Blue)
Secondary:      #58c034 (Green)
Text:           #ffffff (White on dark)
Background:     Dark gradient or solid
```

## Text Guidelines

| Element | Size | Weight | Max Chars |
|---------|------|--------|-----------|
| Title | 72-96px | Bold | 3-5 words |
| Subtitle | 36-48px | Medium | 5-8 words |
| Badge | 24-32px | Bold | 1-2 words |

## Must Have Elements

1. **Main keyword** visible and large
2. **Tech logo/icon** when applicable
3. **Contrasting text** (white on dark, or outlined)
4. **Clear hierarchy** - what is this video about?

## Avoid

- Cluttered designs (max 3 text elements)
- Small text (unreadable on mobile)
- Low contrast colors
- Generic stock photos
- Clickbait that doesn't deliver

## File Naming

```
[PROJECT-CODE]_thumb_v[VERSION].png
Example: SPRING01_thumb_v1.png
```
