# Vlog Thumbnails

Thumbnail guidelines for personal vlog content.

## Specifications

```
Resolution:     1280 × 720 px
Aspect Ratio:   16:9
Format:         PNG or JPG
Max Size:       2 MB
```

## Style Guidelines

- **Tone:** Personal, expressive, authentic
- **Colors:** Warm, inviting, can be vibrant
- **Face:** Almost always include (emotion sells)
- **Text:** Minimal, let the image speak

## Color Palette

```
Primary:        #2e3192 (ArtiVisi Blue)
Warm Accent:    #f4a261 (Orange)
Text:           #ffffff (White, outlined)
```

## Text Guidelines

| Element | Size | Style |
|---------|------|-------|
| Main text | 60-84px | Bold, outlined |
| Emoji/reaction | 72-96px | Native or custom |
| Location | 36-48px | Clean, subtle |

## Emotion Guide

High CTR thumbnails show clear emotion:
- 😲 Surprise/shock
- 😄 Joy/excitement
- 🤔 Curiosity
- 😱 Fear/concern

## Must Have

1. **Your face** with clear emotion
2. **Eye contact** with camera (usually)
3. **Bright, well-lit** image
4. **Minimal text** (1-4 words max)

## Avoid

- Blank/neutral expressions
- Dark/poorly lit photos
- Too much text
- Fake/forced emotions

## File Naming

```
[PROJECT-CODE]_thumb_v[VERSION].png
Example: BALI01_thumb_v1.png
```
