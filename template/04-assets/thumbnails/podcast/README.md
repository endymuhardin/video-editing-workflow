# Podcast Thumbnails

Thumbnail guidelines for video podcast/interview content.

## Specifications

```
Resolution:     1280 × 720 px
Aspect Ratio:   16:9
Format:         PNG or JPG
Max Size:       2 MB
```

## Style Guidelines

- **Tone:** Professional, conversational, branded
- **Colors:** Consistent show branding
- **Faces:** Both host and guest (for interviews)
- **Text:** Episode number, guest name, topic

## ArtiVisi Palette

```
Primary:        #2e3192 (Deep Blue)
Secondary:      #58c034 (Green)
Text:           #ffffff (White)
Background:     Dark or branded gradient
```

## Text Guidelines

| Element | Size | Weight |
|---------|------|--------|
| Show name | 48-60px | Bold |
| Episode title | 36-48px | Medium |
| Guest name | 32-42px | Semibold |
| Episode number | 24-32px | Regular |

## Branding Elements

Consistent across all episodes:
- Show logo position (corner)
- Color scheme
- Font family
- Layout structure

Only change per episode:
- Guest photo
- Episode title
- Episode number

## Guest Photo Tips

1. Request high-res headshot from guest
2. Use consistent crop/framing
3. Match lighting/color grade to your style
4. Professional background or cutout

## Must Have

1. **Show branding** (logo or name)
2. **Episode identifier** (number or title)
3. **Guest face** (for interviews)
4. **Topic hint** (what's discussed)

## File Naming

```
[SHOW]_EP[NUMBER]_thumb_v[VERSION].png
Example: DEVTALK_EP42_thumb_v1.png
```
